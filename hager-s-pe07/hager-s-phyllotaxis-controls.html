About this App

  • Every frame, c (dot spacing), the floret radius, and the divergence angle all increase by a tiny amount
  • Turned magic numbers into set variables and the FPS is set to 60.
  • Restart App button clears the canvas and starts a new flower using the currently selected color scheme.
  • Color Scheme is a dropdown that picks how the dots are colored: Rainbow, Fire, Ocean, Forest, or Grayscale. It takes effect right away on newly drawn dots, so you can switch mid-flower and get bands of different colors.
